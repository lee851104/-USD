# Spec Delta

## Purpose

依影片提出的框架，把「美元指數方向 × 美債利差方向」歸類成四種宏觀組合，並附上曲線型態與訊號強弱，讓使用者一眼知道目前所處的流動性環境。

## ADDED Requirements

### Requirement: 方向判斷使用可選回看期間
系統 SHALL 以回看期間 N 個交易日（可選 20、60、120，預設 20）計算變化量：ΔDXY = DXY(t) − DXY(t−N)、Δ利差 = 利差(t) − 利差(t−N)。ΔDXY > 0 為「美元走強」，否則「美元走弱」；Δ利差 > 0 為「曲線走陡」，否則「曲線走平」。

#### Scenario: 切換回看期間
- **WHEN** 使用者把回看期間從 20 改為 60
- **THEN** 目前組合、指標變化量與歷史色帶都以 60 日重新計算

#### Scenario: 資料不足
- **WHEN** 某日期之前不足 N 筆資料
- **THEN** 該日期不給出組合（顯示為無資料），不得以較短期間代替

### Requirement: 四種組合對應
系統 SHALL 將方向組合對應為以下四種，並顯示影片中的驅動因素與資產表現說明：
1. 美元走強 + 曲線走平 →「流動性最緊縮」
2. 美元走強 + 曲線走陡 →「結構性分化」
3. 美元走弱 + 曲線走陡 →「流動性釋放初期」
4. 美元走弱 + 曲線走平 →「避險主導」

#### Scenario: 美元升、利差降
- **WHEN** ΔDXY = +1.2、Δ利差 = −0.15
- **THEN** 組合為「流動性最緊縮」

#### Scenario: 美元降、利差升
- **WHEN** ΔDXY = −0.8、Δ利差 = +0.10
- **THEN** 組合為「流動性釋放初期」

### Requirement: 曲線型態標籤
系統 SHALL 依 Δ2Y 與 Δ10Y 標示曲線型態：熊平（2Y 升得比 10Y 快）、熊陡（10Y 升得比 2Y 快）、牛陡（2Y 降得比 10Y 快）、牛平（10Y 降得比 2Y 快）；兩者反向時標示為「扭轉陡峭」或「扭轉平坦」。

#### Scenario: 兩端都升，短端較快
- **WHEN** Δ2Y = +0.30、Δ10Y = +0.10
- **THEN** 曲線型態為「熊平」

#### Scenario: 兩端反向
- **WHEN** Δ2Y = −0.10、Δ10Y = +0.05
- **THEN** 曲線型態為「扭轉陡峭」

### Requirement: 訊號強弱
當 |ΔDXY| 小於 DXY(t−N) 的 0.5%，或 |Δ利差| 小於 0.05 個百分點時，系統 SHALL 將該判讀標示為「訊號偏弱」，但仍給出組合。

#### Scenario: 美元幾乎持平
- **WHEN** DXY 從 100.00 變為 100.20、Δ利差 = +0.20
- **THEN** 組合照常判定，並標示「訊號偏弱」
